### 임시 저장 상품 {#1}

[임시저장] 버튼 클릭시, 임시저장 상품 목록에 저장됩니다.

```screen
src: images/prd_regist_01.png

```

### 자체상품코드 {#2}

판매자샵에서 자체적으로 관리하는 상품코드를 입력할 수 있습니다.

- 등록한 자체상품코드로 상품 검색 및 주문 검색이 가능합니다.

### 카테고리 {#3}

등록하실 상품의 카테고리를 입력할 수 있습니다.

- 카테고리 검색 : 검색어를 입력하시면 카테고리가 자동으로 검색됩니다.
- 카테고리 선택 : 분류별 카테고리를 선택할 수 있습니다.

```screen
src: images/prd_regist_03.png
alt: 카테고리
```

### 전시 카테고리 {#4}

판매자샵의 메뉴로 등록될 카테고리를 지정할 수 있습니다.

1. 단일선택 : 한가지의 카테고리에만 등록 할 수 있습니다.
2. 다중선택 : 여러가지의 카테고리에 등록 할 수 있습니다.
3. 신규추가 : 새 카테고리를 생성하여 등록 할 수 있습니다.

```screen
src: images/prd_regit_03.png
alt: 카테고리
```

### 상품명 {#5}

입력한 이름으로 상품 주문서에 표시됩니다.

```screen
src: images/prd_regit_04.png
alt: 상품명
```

### 상품요약 {#6}

- 상품 요약은 원하는 만큼 입력가능하며 내용은 50자로 제한됩니다.
- 환경설정 > 쇼핑몰설정 > 쇼핑몰 스타일 및 기능에서 상품목록_상품요약을 on으로 설정 시 1단레이아웃을 적용했을때 첫번째 상품 요약 내용이 표시됩니다.

```screen
src: images/prd_regit_05.png
alt: 상품요약
```

### 물류업체 {#7}

물류업체를 선택하여 상품을 등록하게 되면 '주문관리'에서 물류업체별로 편리하게 주문관리가 가능합니다.

- 물류업체 추가 및 관리는 환경설정 > 상품 물류업체 관리 > [상품 물류업체 설정](https://srookpay.com/view/new_guide/setting/info07.html)에서 가능합니다.

```screen
src: images/prd_regit_06.png
alt: 물류업체
```

### 제조사/원산지 {#8}

상품의 제조사/원산지를 작성하여 상품을 등록하게 되면 판매자샵 상품페이지에 자동으로 표시됩니다.

```screen
src: images/prd_regit_07.png
alt: 제조사/원산지
```

### 판매상태 {#9}

상품의 판매상태(준비중/판매중/일시품절/완전품절)를 선택하여 등록할 수 있습니다.

- 준비중 : 상품을 미리 업로드 할 경우
- 판매중 : 상품을 바로 판매 하거나 다시 판매할 경우 사용
- 일시품절 : 상품의 재고가 없어 확보 하고 있을 경우
- 완전품절 : 재고가 없는 경우

### 무통장입금 재고수량 체크 기준 {#10}

무통장 입금시의 재고 수량 기준을 선택 할 수 있습니다.

### 상품목록 노출 {#11}

판매자샵 상품 목록에 상품을 노출할지의 공개 여부를 설정 할 수 있습니다.

### 판매기간 설정 {#12}

off - 상시 노출, on -기간설정이 가능합니다.

```screen
src: images/prd_regit_08.png
alt: 판매기간 설정
```

### 결제 수단 {#1}

등록할 상품의 결제 수단을 선택 할 수 있습니다.

### 과세구분 {#2}

과세, 영세, 면세 로 구분되며 매출/정산에서 과세별로 매출을 확인 할 수 있습니다.

### 공급 가격 {#3}

공급가를 입력하면, 매출/정산 > 기간별 매출 관리 > 일별 매출리스트에서 공급 가격과 '판매이익'을 확인 할 수 있습니다.

- 판매이익 = 구매총액 - 공급가 - 수수료
- 공급가는 상품 판매 페이지에 노출되지 않으며 상품 리스트에만 표시됩니다.

```screen
src: images/prd_regit_10.png
alt: 공급 가격
```

### 판매 가격 {#4}

상품을 최종 판매할 가격을 입력 해 주세요.

```screen

alt: 판매 가격
```

### 이전 가격 {#5}

