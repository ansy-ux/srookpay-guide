## 카카오 Business/Developers 설정 안내

- 카카오 비즈니스 계정 생성을 합니다.
- [카카오 디벨로퍼스](https://developers.kakao.com) 사이트에서 카카오 비즈니스 계정으로 로그인한 후 애플리케이션을 생성합니다.
- [카카오 비즈니스](https://business.kakao.com/) 사이트를 열고 [카카오 디벨로퍼스](https://developers.kakao.com) 에서 생성한 애플리케이션과 채널 연결 설정을 하고(채널이 없다면 채널생성 후 연결), 연결된 비즈앱-채널에 카카오 싱크를 신청합니다.
- [카카오 디벨로퍼스](https://developers.kakao.com) 로 돌아와서 카카오 싱크 연동이 되었는지 확인 후, 카카오 로그인 및 간편가입을 위한 설정을 합니다.

## 카카오 Developers 설정

### 애플리케이션 등록 및 설정 {#1}

1. [카카오 디벨로퍼스](https://developers.kakao.com) 에 비즈니스 계정으로 로그인합니다. [(카카오 비즈니스 가입방법)](https://business.kakao.com/)
- 사전에 카카오 비즈니스 계정 생성이 필요하며, 가급적 마스터 계정으로의 로그인을 권장합니다.
2. 상단 메뉴 내 애플리케이션을 클릭한 후 나오는 화면에서 애플리케이션 추가하기 버튼을 클릭합니다.

```screen
src: images/kakao_setting_01.png
alt: 애플리케이션 등록 및 설정
```

3. 애플리케이션 추가하기 팝업에서 관련 정보를 입력합니다.

```screen
src: images/kakao_setting_02.png
alt: 애플리케이션 등록 및 설정
```

4. 생성된 애플리케이션을 클릭합니다.

```screen
src: images/kakao_setting_03.png
alt: 애플리케이션 등록 및 설정
```

5. 플랫폼 설정하기 버튼을 클릭하여 플랫폼 페이지로 진입 후, Web 플랫폼 등록을 클릭합니다.

```screen
src: images/kakao_setting_04.png
alt: 애플리케이션 등록 및 설정
```

6. Web 플랫폼 등록 팝업에서 사이트 도메인에 https://srookpay.com를 입력 후 저장합니다.
- 입력값 : https://srookpay.com https://srookpay.co.kr https://admin.srookpay.com https://instashop.srookpay.com https://kakao.srookpay.com

```screen
src: images/kakao_setting_05_1.png
alt: 애플리케이션 등록 및 설정
```

7. 상단 햄버거 메뉴를 클릭 후 앱설정 > 비즈니스 메뉴를 클릭합니다. 비즈 앱 정보에서 [사업자 정보 등록] 버튼을 클릭하여 사업자 등록번호를 입력하고 [확인] 버튼을 클릭합니다.

```screen
src: images/kakao_setting_06.png
alt: 애플리케이션 등록 및 설정
```

8. 해당 사업자 등록번호에 해당하는 사업자 정보가 자동으로 입력이 됩니다. 동의 후 저장버튼을 클릭합니다.

```screen
src: images/kakao_setting_07.png
alt: 애플리케이션 등록 및 설정
```

## 카카오 Business 설정

### 채널-앱 연결하기 {#2}

1. [카카오 비즈니스](https://business.kakao.com/) 계정으로 로그인하고, 상단 [내 비즈니스] 버튼을 클릭하여 비즈니스 관리자 센터로 이동합니다. 비즈니스 관리자 센터의 좌측 메뉴 비즈니스 설정에서 채널-앱 연결 메뉴를 클릭하여 해당 메뉴로 이동합니다.

```screen
src: images/kakao_setting_08.png
alt: 채널-앱 연결하기
```

2. 채널-앱 연결관리 페이지에서 [비즈앱-채널 연결하기] 버튼을 클릭합니다.

```screen
src: images/kakao_setting_09.png
alt: 채널-앱 연결하기
```

3. 디벨로퍼스에서 생성한 앱을 클릭 후, 우측의 비즈니스 채널의 체크박스에 체크 후 연결하기를 클릭합니다. 비즈니스 채널이 없다면 비즈니스 채널 하단의 비즈니스 채널 신청하기 링크나 상단 채널메뉴를 통해 새 채널을 생성 후 연결합니다.

```screen
src: images/kakao_setting_11.png
alt: 채널-앱 연결하기
```

4. 채널-앱 연결이 완료 되었으면, 카카오싱크 신청을 위해 좌측 메뉴에서 카카오싱크 메뉴로 진입 후 [개인정보 항목 신청] 버튼을 클릭 합니다.

```screen
src: images/kakao_setting_12.png
alt: 채널-앱 연결하기
```

5. 호스팅사 사용여부- 호스팅사에 속하지 않는 독립몰에 체크 후 [다음] 버튼을 클릭합니다.

```screen
src: images/kakao_setting_13.png
alt: 채널-앱 연결하기
```

6. 권한 신청에 필요한 상세 내용을 작성합니다.
- 필수 수집항목과 선택 수집항목은 스룩페이샵의 회원 가입 페이지의 개인정보 수집 및 이용동의와 동일하게 선택합니다.
- 필수 수집항목 : 프로필/닉네임, 이메일, 전화번호, 이름
- 선택 수집항목 : 성별

```screen
src: images/kakao_setting_14.png
alt: 채널-앱 연결하기
```

- 수집사유 : 스룩페이 샵 회원 가입 및 관리, 재화 또는 서비스 제공, 고충처리, 재가입 및 부정이용방지, 맞춤형 회원관리 서비스 제공
- 서비스 회원가입 링크 URL : https://instashop.srookpay.com/(상점아이디)/Member/MemberJoinDetail?prevUrl=
- 사이트 내 회원가입 페이지 필수항목 확인 가능 자료 : 스룩페이샵 회원가입 페이지 이미지 캡쳐본 업로드

## 스룩페이샵 회원가입 페이지 이미지 캡쳐 방법

1. 판매자샵에 접속합니다
2. 좌측 상단 햄버거 메뉴 클릭후 회원가입을 클릭합니다.
3. 로그인 화면에서 이메일로 회원가입 버튼을 클릭합니다.
4. 링크주소가 보이도록 화면을 캡쳐 합니다.

```screen
src: images/kakao_setting_15.png
alt: 스룩페이샵 회원가입 페이지 이미지 캡쳐 방법 화면
```

```screen
src: images/kakao_setting_16.png
alt: 스룩페이샵 회원가입 페이지 이미지 캡쳐 방법 화면
```

7. 완료 버튼 클릭 시 카카오 싱크 신청이 완료 됩니다.
- 카카오싱크 페이지에서 신청한 비즈앱과 비즈니스 채널을 확인 할 수 있으며, 카카오싱크 신청 검수는 약 D+0.5에서 (휴일을 제외한) D+1 소요됩니다.
- 카카오싱크 신청 검수에서 반려되었다면, [검수 결과 확인] 버튼을 선택하여 검수 결과를 확인하고 [개인정보 항목 신청] 버튼을 선택하여, 카카오싱크 재신청이 가능 합니다.

```screen
src: images/kakao_setting_17.png
alt: 스룩페이샵 회원가입 페이지 이미지 캡쳐 방법 화면
```

## 카카오 Developers 추가 설정

### 카카오 로그인 설정 및 기타 설정 {#3}

1. [카카오 디벨로퍼스](https://developers.kakao.com) 사이트 접속 후 상단의 [내 애플리케이션] 메뉴를 클릭합니다. 내 애플리케이션 페이지에서 카카오싱크 연동이 되었는지 확인 후 어플리케이션을 클릭합니다. (Biz, Channel이 추가 되었는지 확인)

```screen
src: images/kakao_setting_18.png
alt: 카카오 로그인 설정 및 기타 설정
```

2. 좌측 메뉴에서 카카오 로그인 메뉴를 클릭 한 후 활성화 설정의 상태를 ON으로 변경하여 카카오 로그인을 활성화 합니다.

```screen
src: images/kakao_setting_19.png
alt: 카카오 로그인 설정 및 기타 설정
```

3. [Redirect URL 등록] 버튼을 클릭하여 Redirect URI 팝업 내 Redirect URI를 입력 합니다.
- Redirect URL 등록 내용 : https://instashop.srookpay.com/Member/kakaoSyncRedirect https://kakao.srookpay.com/Member/kakaoSyncRedirect https://instashop.srookpay.com/Member/kakaoSyncRedirectAdd https://kakao.srookpay.com/Member/kakaoSyncRedirectAdd https://instashop.srookpay.com/Member/kakaoSyncAutoLogin https://kakao.srookpay.com/Member/kakaoSyncAutoLogin https://instashop.srookpay.com/Member/kakaoSyncRedirectTest https://instashop.srookpay.com/Member/oAuthRedirect

```screen
src: images/kakao_setting_20_1_1.png
alt: 카카오 로그인 설정 및 기타 설정
```

4. 좌측 메뉴중 카카오 로그인 > 간편가입 메뉴를 클릭 후 [서비스 약관 추가] 버튼을 클릭하여 해당 내용을 작성합니다.

```screen
src: images/kakao_setting_21.png
alt: 카카오 로그인 설정 및 기타 설정
```

- **∘ 서비스 약관은 총 다섯번 입력 하며, [서비스 약관 추가] 버튼 클릭 후 서비스 약관추가 팝업에 하단의 내용 입력-저장 후 [서비스 약관 추가] 버튼을 다시 클릭, 팝업 내용 입력-저장하는 방법으로 총 다섯번 반복합니다.**

```screen
src: images/kakao_setting_22.png
alt: 카카오 로그인 설정 및 기타 설정
```

5. [만 14세 이상 연령 동의 추가] 버튼을 클릭하여 해당 내용을 작성합니다.

```screen
src: images/kakao_setting_23.png
alt: 카카오 로그인 설정 및 기타 설정
```

6. 입력한 약관을 **모두** [활성화] 버튼을 클릭하여 활성화로 변경 하고, 사용여부 스위치를 ON으로 변경합니다.

```screen
src: images/kakao_setting_24.png
alt: 카카오 로그인 설정 및 기타 설정
```

7. 좌측 메뉴 '동의 항목' 페이지 진입 후 카카오 로그인으로 서비스를 시작할때 동의 받는 항목을 설정합니다.
- 필수 동의 : 카카오계정(이메일), 이름, 전화번호 이메일과 이름의 경우 '카카오 계정으로 정보 수집 후 제공 체크' ∘ 선택 동의 : 성별(수집하지 않음)

```screen
src: images/kakao_setting_25.png
alt: 카카오 로그인 설정 및 기타 설정
```

8. 좌측 메뉴 '카카오톡 채널'을 클릭하여 페이지 진입 후 [대표 채널 선택] 버튼을 클릭하여 나오는 팝업에서 대표 채널 선택 후 저장버튼을 클릭합니다.

```screen
src: images/kakao_setting_26_1.png
alt: 카카오 로그인 설정 및 기타 설정
```

9. 좌측 메뉴 '연결 끊기'를 클릭하여 페이지 진입 후 [연결 끊기 등록] 버튼을 클릭하여 나오는 연결끊기 등록 팝업에서 해당 내용을 입력 합니다.
- 콜백 URL : https://instashop.srookpay.com
- POST 선택
- /{상점아이디}/Member/UnlinkKakaoSync

```screen
src: images/kakao_setting_27_1.png
alt: 카카오 로그인 설정 및 기타 설정
```

10. 좌측 메뉴 '보안'을 클릭하여 페이지 진입 후 [코드 생성] 버튼을 클릭하여, Client Secret 코드를 생성합니다.
- 입력 https://instashop.srookpay.com/Member/ShopLogout https://kakao.srookpay.com/Member/ShopLogout

```screen
src: images/kakao_setting_28_1.png
alt: 카카오 로그인 설정 및 기타 설정
```

11. 좌측 메뉴 '고급'을 클릭하여 페이지 진입 후 ]Logout Redirect URI 등록] 버튼을 클락하여 다음의 내용을 입력합니다.
- 입력 https://instashop.srookpay.com/Member/ShopLogout https://kakao.srookpay.com/Member/ShopLogout

```screen
src: images/kakao_setting_29.png
alt: 카카오 로그인 설정 및 기타 설정
```
