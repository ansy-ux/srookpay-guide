## 이지어드민 안내

이지어드민 페이지에서 이지어드민에 대한 설명을 확인할 수 있으며, 이지어드민 가입 페이지로 진입할 수 있습니다.

```screen
src: images/ezadmin_01.png
alt: 이지어드민 안내
```

① 이지어드민 서비스 안내와 신청 방법이 노출 됩니다.

② [이지어드민 신청하기] 버튼 클릭 시, 새로운 탭이나 브라우저로 이지어드민 무료사용신청 페이지가 노출 됩니다.

## 무료사용 신청

이지어드민 무료사용신청 페이지에서 이지어드민 가입을 할 수 있습니다.

```screen
src: images/ezadmin_02.png
alt: 무료사용 신청
```

① 절차에 따라 필수값 및 선택값을 입력하거나 클릭하여, 회원가입을 진행합니다

② 필수값을 모두 입력 및 클릭하고 [신청하기] 버튼 클릭 시, 이지어드민 가입이 완료 됩니다.

## 스룩페이 환경설정(1)

이지어드민 가입 후, 환경설정 페이지에서 이지어드민 연동키를 생성할 수 있습니다.

```screen
src: images/ezadmin_03.png
alt: 스룩페이 환경설정(1)
```

① [KEY 발급하기] 버튼 클릭 시, 서비스 연동 팝업이 노출 됩니다.

② 서비스 연동 팝업에서 필수값을 모두 선택하고 [적용] 버튼 클릭 시, 이지어드민 연동키가 생성 됩니다.

③ 이카운트와 셀메이트와 연동된 상태에서 [적용] 버튼을 클릭하면, 이카운트 연동 해제 Alert이나 셀메이트 연동 해제 Alert이 노출되며 이지어드민 연동키가 생성되지 않습니다.

## 스룩페이 환경설정(2)

환경설정 페이지에서 생성한 이지어드민 연동키를 확인할 수 있으며, 연동을 해제할 수 있습니다.

```screen
src: images/ezadmin_04.png
alt: 스룩페이 환경설정(2)
```

① 이지어드민 연동키가 노출 됩니다.

② [KEY 복사] 버튼 클릭 시, 이지어드민 연동키가 복사 됩니다.

③ 연동일이 노출 됩니다.

④ [연동해제] 버튼 클릭 시, 이지어드민 연동키 연동을 해제할 수 있습니다.

## 상품 물류업체 설정

상품 물류업체 관리 > 상품 물류업체 설정 페이지에서 상품 물류업체와 이지어드민 연동을 설정 할 수 있습니다.

```screen
src: images/ezadmin_05.png
alt: 상품 물류업체 설정
```

① 이지어드민 연동 체크박스 클릭 시, 이지어드민 연동 여부를 선택할 수 있습니다.

② 이지어드민 연동 체크박스를 클릭하고 [적용] 버튼 클릭 시, [적용] 버튼에 해당하는 상품 물류업체의 이지어드민 연동 여부 선택이설정(저장) 됩니다. 2개 이상의 상품 물류업체가 연동된 상태에서 [적용] 버튼 클릭 시, 같이 수정 Alert이 노출 됩니다.

③ 같이 수정 Alert에서 [확인] 버튼을 클릭하면 연동된 다른 상품 물류업체의 이지어드민 연동 여부 선택이 설정(저장)되며, [취소] 버튼을 클릭하면 [적용] 버튼에 해당하는 상품 물류업체의 이지어드민 연동 여부 선택만 설정(저장) 됩니다.
