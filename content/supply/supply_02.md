### 날짜검색 {#1}

발주서 생성일 / 메일발송일 / 수신완료일 선택한 후에, 시작일과 종료일을 입력하거나 선택 수 있습니다. 오늘/1주일/1개월/2개월/6개월 버튼을 클릭하면, 클릭한 버튼에 해당하는 날짜가 자동으로 선택 됩니다.

### 상품물류업체 {#2}

물류업체를 선택하여 해당 발주를 검색할 수 있습니다.

### 발주번호 {#3}

발주번호를 입력할 수 있습니다.

### 발주요청상태 {#4}

전체/발주서 생성/메일발송 중수신완료를 선택할 수 있습니다.

### 메일발송 후 경과일 {#5}

전체/1일 이상/2일 이상/3일 이상/4일 이상/5일 이상/6일 이상/7일 이상을 선택할 수 있습니다.

### 상품명 {#6}

상품명을 입력하거나 [상품 찾기>] 버튼을 클릭하면 상품을 검색할 수 있는 상품 찾기 팝업이 노출되며, 팝업에서 상품을 검색 및 선택할 수 있습니다.

### 연락처 {#7}

연락처를 입력할 수 있습니다.

### 주문자명 {#8}

주문자명을 입력할 수 있습니다.

### 검색, 초기화 버튼 {#9}

검색 버튼을 클릭하면 발주보류 검색에서 선택 및 입력값 기준으로 발주보류 주문을 검색할 수 있으며, 초기화 버튼을 클릭하면 발주보류 검색에서 선택 및 입력값이 초기화 됩니다.

### 메일발송 or 재발송 {#1}

선택한 주문건을 지정된 물류업체 메일을 발송합니다.

- 메일 발송 or 재발송 시 "메일 발송 중"으로 넘어갑니다.

```screen
src: images/supply_5_3.png
alt: 메일발송 or 재발송
```

### 발주서 엑셀 내려받기 {#2}

선택한 주문건의 엑셀을 내려받을 수 있습니다.

```screen
src: images/supply_5_4.png
alt: 발주서 엑셀 내려받기
```

### 발주상태 {#3}

현재 발주 상태를 나타냅니다.

- 메일발송중 - 메일을 물류업체 메일로 전송한 상태 발주서 생성 - 해당 주문건을 메일발송 없이 발주서만 생성 수신완료 - 해당 물류업체가 메일을 수신완료

```screen
src: images/supply_5_5.png
alt: 발주서 엑셀 내려받기
```

### 발주일 {#4}

발주서생성 일 / 메일발송일 일을 확인할 수 있습니다.

```screen
src: images/supply_5_6.png
alt: 발주일
```

### 발주번호 {#5}

발주 시 발주번호가 생성됩니다. 발주서를 엑셀로 내려받을 수 있고, 주문 상세보기 클릭 시 상세보기 팝업이 노출됩니다.

```screen
src: images/supply_5_7.png
alt: 발주일
```

### 메일발송수 경과일 {#6}

메일 발송횟수를 확인할 수 있으며, 발송일로부터 수신하기 전까지의 경과일을 확인할 수 있습니다.

```screen
src: images/supply_5_8.png
alt: 발주일
```

### 물류업체 / 메일주소 / 담당자명 {#7}

물류업체명 / 물류업체 이메일 / 물류업체 담당자명을 확인할 수 있습니다.

- 메일주소를 확인하여 메일발송에 차질이 생기지 않게 주의 해주시기 바랍니다.

```screen
src: images/supply_5_9.png
alt: 물류업체 / 메일주소 / 담당자명
```

### 엑셀양식명 생성방식 {#8}

엑셀양식과 생성방식을 확인할 수 있습니다.

- 엑셀 생성 방식은 환경설정 > 상품 물류업체 관리 > 상품 물류업체 설정에서 수정 가능합니다.

```screen
src: images/supply_5_10.png
alt: 엑셀양식명 생성방식
```

### 상품명/주문수/상품수/파일수 {#9}

상품명 - 해당 상품의 이름 주문수 - 해당 발주서의 주문수 상품수 - 해당 발주서에 주문한 상품수 파일수 - 메일 발송건의 엑셀 파일 수
