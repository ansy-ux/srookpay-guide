## 카카오싱크 설정하기

- 카카오싱크 : 간편가입으로 회원을 쉽고 빠르게 가입전환으로 유도하여 구매까지 연결시켜 주는 서비스 입니다.

```screen
src: images/kakao_sync_01.png
alt: 카카오싱크 설정하기 화면
1: 23.7 31.2
2: 46.6 30.9
```

### 대행요청 {#1}

카카오 싱크대행을 선택하시면 운영자가 확인하여 진행에 도움을 드립니다.

- 카카오싱크 대행 요청을 하기 위해 카카오 비즈니스계정이 필요합니다. [(카카오 비즈니스 가입방법)](https://business.kakao.com)
- 카카오 비즈니스 아이디를 필수로 입력해야 대행요청이 가능합니다.

```screen
src: images/kakao_sync_02.png
alt: 대행요청
```

### 직접진행 {#2}

카카오 business 및 카카오 developers 설정을 완료하고,진행 중에 나오는 REST API 키 및 Javascript 키, Client Secret 코드를 입력하고 테스트를 진행하여 적용을 완료 합니다.

- ([카카오 business 설정](https://business.kakao.com/) 및 [카카오 developers 설정](https://developers.kakao.com/) 방법)

```screen
src: images/kakao_sync_03.png
alt: 직접진행
```

**ⓐⓑ REST API, Javascript 키 입력방법**

- [카카오 developers](https://developers.kakao.com/)사이트에 로그인 후 상단 내 애플리케이션 메뉴를 클릭하여, 설정을 마친 애플리케이션을 클릭합니다.

```screen
src: images/kakao_sync_04.png
alt: 직접진행
```

- 다음 페이지에 나와있는 REST API키와 Javascript키를 복사해서 관리자 페이지에 입력합니다.

```screen
src: images/kakao_sync_05.png
alt: 직접진행
```

**ⓒ Client Secret 코드 입력 방법**

- [카카오 developers](https://developers.kakao.com/) 사이트에서 좌측 '보안' 메뉴를 클릭 후 나오는 Client Secret 페이지에서 코드를 복사하여 관리자 페이지에 입력합니다.

```screen
src: images/kakao_sync_06.png
alt: 직접진행
```

### 설정완료 {#3}

**: 설정이 완료 되면 수정이 불가하며 자동로그인 설정을 할 수 있습니다.**

- 사용안함 : 인앱 사용 시 자동 로그인을 사용하지 않습니다.
- 구매하기 클릭 시 : 인앱 사용 시 구매하기 클릭 시 자동로그인 됩니다.
