### 송장일괄등록 {#1}

송장번호가 입력된 파일을 공급사에서 전달 받으셨다면 ‘송장일괄등록’ 버튼을 클릭하여 화면 이동합니다. 아래 화면에서 엑셀 파일을 업로드하면 주문상태가 자동으로 배송중으로 변경됩니다.

### 송장자동처리 {#2}

송장 자동 처리 버튼 클릭 시 운송장 출력 확인 페이지로 이동합니다.

### 굿스플로 묶음배송 {#3}

선택된 주문건의 묶음배송을 처리를 할 수 있습니다.

### 미입금 {#4}

미입금 클릭 시 선택된 주문건이 미입금 상태로 변경됩니다.

### 주문확인 {#5}

주문이 확인 되면 주문건들을 선택 후 주문확인 처리합니다. 주문상태가 배송준비로 변경 됩니다.

### 배송예약 {#6}

배송시간이 예약 된 주문건은 배송예약 처리됩니다.
