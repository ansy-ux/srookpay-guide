## 자주 묻는 질문

### 무통장 자동입금확인은 어떤 기능인가요?

무통장으로 주문 받을 경우 입금 여부를 별도 확인할 필요 없이 자동으로 입금확인 처리 해주는 서비스 입니다.

```screen
src: images/faq01.gif
alt: 무통장 자동입금확인 - 무통장으로 주문 받을 경우 자동으로 입금확인 처리 해주는 서비스
```

### 입금 됐는데 입금확인 처리가 되지 않아요.

주문서의 입금자명과 실제 입금한 이름이 동일한지 확인해야 합니다. 동일하지 않을 경우 입금확인 불가 처리 됩니다.

```screen
src: images/faq02.gif
alt: 주문서의 입금자명과 실제 입금한 이름이 동일하지 않을 경우 입금확인 불가 처리
```

### 입금자명과 입금한 사람의 이름이 같아도 입금확인 처리가 안될 수 있나요?

네. 같은 이름과 같은 금액이 있을 경우 처리 불가로 입금확인이 안됩니다.

```screen
src: images/faq03.gif
alt: 같은 이름과 같은 금액이 있을 경우 처리 불가
```

### 무통장 자동입금확인 기능은 무조건 믿을 수 있나요?

아닙니다. 무통장입금알림 서비스는 기술적 한계로 실제 은행의 거래내역과 차이가 발생할 수 있습니다. 은행의 실제 거래내역을 기준으로 확인 하는 것이 가장 정확합니다.

```screen
src: images/faq04.gif
alt: 무통장입금알림 서비스는 기술적 한계로 실제 은행의 거래내역과 차이가 발생할 수 있음
```

### 스룩페이 아이디가 2개 이상이어도 이용할 수 있나요?

네. 스룩페이 무통장 알리미 앱에서 아이디를 추가하여 사용할 수 있습니다.

```screen
src: images/faq05.gif
alt: 스룩페이 무통장 알리미 앱에서 아이디를 추가하여 사용 가능
```

### 무통장 계좌가 2개 이상이어도 이용할 수 있나요?

네. 스룩페이 무통장 알리미 앱에서 계좌정보를 추가하여 사용할 수 있습니다.

```screen
src: images/faq06.gif
alt: 스룩페이 무통장 알리미 앱에서 계좌정보를 추가하여 사용 가능
```

### 스룩페이 아이디가 여러개일 경우 입금확인된 내역은 모든 아이디에 나오나요?

아닙니다. 아이디가 여러개일 경우 그룹지은 최초 아이디에서만 모든 내역이 나오며, 나머지 추가한 아이디에서는 입금확인 처리된 내역만 나옵니다.
