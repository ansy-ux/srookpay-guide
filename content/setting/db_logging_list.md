## 변경이력

```screen
src: images/db_logging_list_01.png
alt: 변경이력
captured: 2026-10
1: 7.9 27.5
2: 24.6 27.5
3: 40.9 27.5
4: 62.1 27.5
5: 85 27.5
```

### 아이디 {#1}

변경을 진행한 아이디가 노출됩니다.

```screen
src: images/db_logging_list_02.png
alt: 아이디
```

### 구분 {#2}

변경을 진행한 아이디의 구분입니다. 마스터 아이디면 ‘마스터’로 노출되고, 부계정 아이디면 ‘서브’로 노출됩니다.

```screen
src: images/db_logging_list_03.png
alt: 구분
```

### 메뉴 {#3}

변경된 페이지 메뉴 경로가 노출되며, 메뉴 경로를 클릭하면 새로운 웹 브라우저 탭이나 창을 띄워 변경된 페이지로 이동합니다.

```screen
src: images/db_logging_list_04.png
alt: 메뉴
```

### 변경사항 {#4}

변경된 사항이 노출됩니다. 상품 수정이나 주문 수정 등은 상세 내역을 확인하실 수 있으며, 주문번호나 상품번호를 클릭 시 변경된 상세내역을 확인할 수 있습니다.

```screen
src: images/db_logging_list_05.png
alt: 변경사항
```

### 변경일자 {#5}

데이터를 변경한 날짜가 노출됩니다.

```screen
src: images/db_logging_list_06.png
alt: 변경일자
```
