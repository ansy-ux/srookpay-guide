## 샘플 요청 검색

```screen
src: images/celeb_sample_list_01.png

1: 1.0 23.7

```

### 검색 {#1}

셀럽명 / 셀럽이름 / 상품명 / 셀럽요청번호를 선택한 후에 검색내용을 입력할 수 있습니다.

### 상태 {#2}

전체 / 발송 요청 / 발송 승인 / 요청 반려 / 발송중 / 발송 완료 / 수령 완료 / 요청 취소 / PICK 요청 / 판매거부를 선택할 수 있습니다.

### 요청날짜 {#3}

시작일과 종료일을 입력하거나 선택 수 있습니다. 그리고 오늘 / 1주일 / 1개월 / 2개월 / 전체 버튼을 클릭하면, 클릭한 버튼에 해당하는 날짜가 자동으로 선택 됩니다.

### 최초결제일자 {#4}

시작일과 종료일을 입력하거나 선택 수 있습니다. 그리고 오늘 / 1주일 / 1개월 / 2개월 / 전체 버튼을 클릭하면, 클릭한 버튼에 해당하는 날짜가 자동으로 선택 됩니다.

### 검색, 초기화 버튼 {#5}

검색 버튼을 클릭하면 샘플 요청 검색에서 선택 및 입력값 기준으로 샘플 요청 건을 검색할 수 있으며, 초기화 버튼을 클릭하면 샘플 요청 검색에서 선택 및 입력값이 초기화 됩니다.

## 샘플 요청 리스트

```screen
src: images/celeb_sample_list_02_01.png
alt: 샘플 요청 리스트
```

### 상태변경 {#1}

샘플 요청 건을 선택하고 발송요청 / 발송승인 / 요청취소 / 발송반려 / 발송중 / 발송완료를 선택할 수 있으며, 선택한 이후에 [적용] 버튼을 클릭하면 선택한 샘플 요청 건의 상태를 변경할 수 있습니다.

### 선택 엑셀 내려받기 {#2}

샘플 요청 건을 선택하고 [선택 엑셀 내려받기>] 버튼을 클릭하면 선택한 샘플 요청 건에 해당하는 엑셀 파일을 다운로드 받을 수 있습니다.

### 전체 엑셀 내려받기 {#3}

[전체 엑셀 내려받기>] 버튼을 클릭하면 전체 샘플 요청 건에 해당하는 엑셀 파일을 다운로드 받을 수 있습니다.

### 송장일괄등록 {#4}

[송장일괄등록] 버튼을 클릭하면 샘플 송장일괄등록 팝업이 노출되며 샘플 송장 엑셀 파일을 업로드할 수 있습니다.

```screen
src: images/celeb_sample_list_02_02.png
alt: 송장일괄등록
```

### 샘플발송추가 {#5}

[샘플발송추가] 버튼을 클릭하면 샘플 발송 추가 팝업이 노출 됩니다.

### 상태변경 {#6}

발송요청 / 발송승인 / 요청취소 / 발송반려 / 발송중 / 발송완료를 선택할 수 있으며, 선택한 이후에 상태변경 Alert에서 [확인] 버튼을 클릭하면 선택한 상태로 샘플 요청 건의 상태변경이 됩니다. 발송승인 상태에서 [송장번호 등록] 버튼이 노출되며 송장번호를 등록할 수 있고, 발송중과 발송완료 상태에서 [배송조회] 버튼이 노출되며 배송조회를 할 수 있습니다.

```screen
src: images/celeb_sample_list_02_03.png
alt: 상태변경
```

### 관리자 메모 {#7}

관리자 메모를 입력 및 수정할 수 있습니다.

```screen
src: images/celeb_sample_list_02_04.png
alt: 관리자 메모
```

## 샘플 발송 추가 팝업

```screen
src: images/celeb_sample_list_03_01.png
alt: 샘플 발송 추가 팝업
```

### 셀럽명 {#1}

[찾기] 버튼을 클릭하면 셀럽 찾기 팝업이 노출되며, 팝업에서 셀럽을 검색 및 선택할 수 있습니다.

```screen
src: images/celeb_sample_list_03_02.png
alt: 셀럽명
```

### 상품명 {#2}

셀럽을 선택하고 [찾기] 버튼을 클릭하면 상품을 검색할 수 있는 상품 찾기 팝업이 노출되며, 팝업에서 상품을 검색 및 선택할 수 있습니다.

```screen
src: images/celeb_sample_list_03_03.png
alt: 상품명
```

### 수령자 {#3}

수령자를 입력할 수 있습니다.

### 연락처 {#4}

연락처를 입력할 수 있습니다.

### 주소 {#5}

[주소검색] 버튼을 클릭하면 팝업 내에 우편번호 서비스 팝업이 노출되며 주소를 선택하면 선택한 주소가 노출되며, 상세주소를 입력할 수 있습니다.

### 취소, 등록 버튼 {#6}

[취소] 버튼을 클릭하면 샘플 발송 추가가 취소되며, [등록] 버튼을 선택하면 샘플 발송 추가됩니다.

## 샘플 요청 상세정보

```screen
src: images/celeb_sample_list_04_01.png
alt: 샘플 요청 상세정보
captured: 2026-10
1: 10.2 2.7
2: 36.4 31.1
3: 11.4 40.3
4: 10.3 57.7
5: 10.3 95.6
6: 10.3 99.0
7: 88.3 99.0
8: 14.7 99.0
9: 12.7 99.0
```

### 요청상태 {#1}

요청날짜 / 요청번호 / 현재상태가 노출됩니다.

### 블랙리스트 지정 {#2}

[블랙리스트 지정] 버튼을 클릭하면 요청 셀럽을 블랙리스트로 지정할 수 있습니다.

### 상태변경 {#3}

전처리건수가 노출되며, 처리건수(완료/실패)를 클릭하면 취소 요청 상세 팝업이 노출되며, 취소 요청 상세 내역이 노출 됩니다.

### 요청정보 {#4}

샘플 요청 시 작성한 요청 메시지가 노출 됩니다.

### 요청셀럽 {#5}

요청 셀럽의 세부 정보가 노출 됩니다.

### 요청상품 {#6}

요청 상품의 세부 정보가 노출됩니다.

### 송장등록 {#7}

요청 상품에 해당하는 송장이 노출되며, 송장번호를 수정할 수 있습니다.

### 상태 변경 기록 {#8}

샘플 요청 건에 해당하는 상태 변경 기록이 노출 됩니다.

### 수령지 정보 {#9}

수령지 정보가 노출되며 [우편번호 찾기] 버튼을 클릭하면 우편번호 서비스 팝업이 노출되며 주소를 선택하면 선택한 주소가 노출되며, 상세주소를 수정할 수 있습니다.

### 관리자 메모 {#10}

관리자 메모가 노출되며 관리자 메모를 수정할 수 있습니다.
