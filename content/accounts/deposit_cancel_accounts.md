## 예치금 계좌관리

```screen
src: images/deposit_cancel_accounts_title.png
alt: 예치금 가상계좌 검색
captured: 2026-10
1: 0.6 28.6
2: 0.6 44
3: 0.6 59.6
4: 44 77.1
```

### 가상 계좌번호 {#1}

가상 계좌번호를 입력할 수 있습니다.

### 요청날짜 {#2}

시작일과 종료일을 입력하거나 선택 수 있습니다. 그리고 오늘 / 1주일 / 1개월 / 2개월 / 6개월 버튼을 클릭하면, 클릭한 버튼에 해당하는 날짜가 자동으로 선택 됩니다.

### 주문검색 {#3}

전체 / 입금대기 / 취소완료 / 가상계좌만료 / 입금취소 / 부분실패를 선택할 수 있습니다.

### 검색, 초기화 버튼 {#4}

검색 버튼을 클릭하면 예치금 가상계좌 검색에서 선택 및 입력값 기준으로 가상계좌 검색할 수 있으며, 초기화 버튼을 클릭하면 예치금 가상계좌 검색에서 선택 및 입력값이 초기화 됩니다.

```screen
src: images/deposit_cancel_accounts_02_title.png
alt: 가상계좌 리스트
1: 4.1 47.8
2: 24.1 32.5
3: 30.5 32.5
```

### 가상계좌 리스트 {#1}

가상계좌 리스트: 가상계좌에 해당하는 상세 내역이 노출 됩니다.

### 요청건수 {#2}

요청건수가 노출되며 요청건수를 클릭하면 취소 요청 상세 팝업이 노출되며, 취소 요청 상세 내역이 노출 됩니다.

### 처리건수(완료/실패) {#3}

전처리건수가 노출되며, 처리건수(완료/실패)를 클릭하면 취소 요청 상세 팝업이 노출되며, 취소 요청 상세 내역이 노출 됩니다.
