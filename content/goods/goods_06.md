## 공급사 관리 검색

```screen
src: images/supply_01.png
alt: 공급사 관리 검색 화면
captured: 2026-10
1: 1.6 63.5
2: 33 63.3
```

### 계정검색 {#1}

카테고리명을 입력하여 새 카테고리를 생성합니다.

### 승인상태 {#2}

선택한 카테고리 상태(보임/숨김)를 변경하거나 삭제 할 수 있습니다.

## 공급사 관리 리스트

```screen
src: images/supply_02.png
alt: 공급사 관리 리스트 화면

```

### 공급사 가입 URL 복사 {#1}

공급사 URL을 복사 할수 있습니다.

### 공급사명 {#2}

공급사명이 노출됩니다.

```screen
src: images/supply_03.png
alt: 공급사명
```

### 아이디/이메일 {#3}

공급사 이메일이 노출됩니다. 이메일을 통한 마케팅 정보 수신 여부가 함께 노출됩니다.

```screen
src: images/supply_04.png
alt: 아이디/이메일
```

### 대표자명 {#4}

대표자명이 노출됩니다.

```screen
src: images/supply_05.png
alt: 대표자명
```

### 대표번호/가입일 {#5}

대표번호 및 가입일이 노출됩니다. SMS을 통한 마케팅 정보 수신 여부가 함께 노출됩니다.

```screen
src: images/supply_06.png
alt: 대표번호/가입일
```

### 메모 {#6}

⑧관리-상세 버튼 클릭시 나오는 공급사 정보보기에서 관리자 메모에 입력한 내용이 노출됩니다.

```screen
src: images/supply_07.png
alt: 메모
```

### 승인상태 {#7}

해당 공급사를 거부 및 승인 할 수 있습니다.

```screen
src: images/supply_08.png
alt: 승인상태
```

### 관리 {#8}

상세 버튼을 누르면 해당 공급사 정보를 확인 할 수 있습니다.

```screen
src: images/supply_09.png
alt: 관리
```
