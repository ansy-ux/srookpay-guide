### 초기화 {#1}

[초기화] 버튼 클릭 시, 가장 최근 [판매자샵 디자인 적용]을 적용한 시점으로 원복됩니다.

### 디자인 템플릿 보기 {#2}

디자인 템플릿 리스트를 확인하고 적용할 수 있습니다.

```screen

```

### 미리보기 {#3}

설정한 판매자샵을 게시하기 전에 미리볼 수 있습니다.

```screen

alt: 미리보기
```

### 판매자샵 디자인 적용 {#4}

설정한 판매자샵 레이아웃이 쇼핑몰에 실제로 반영됩니다.

### 레이아웃 {#5}

레이아웃 명을 지정한 후 [레이아웃 신규 저장] 버튼 클릭시 설정한 레이아웃을 추가할 수 있습니다. 레이아웃은 최대 10개까지 저장 가능합니다.

- 판매자샵에 현재 적용되어 있는 레이아웃에 ‘적용중’ 표시가 됩니다.

```screen
src: images/main_display_04.png
alt: 레이아웃
```


### 판매자샵 설정 영역 {#1}

우측 모듈 리스트에서 선택한 모듈을 드래그&드랍하면 왼쪽 판매자샵 설정에 반영 됩니다.

- 설정 된 영역에 마우스 오버 시 [수정][삭제] 버튼이 노출됩니다.
- [수정] 버튼 클릭시, 해당 영역의 설정이 가능합니다.
- 수정 후 [저장] 버튼을 누르셔야 설정된 내용이 적용됩니다.

```screen
src: images/main_display_06.png
alt: 판매자샵 설정 영역
```

### 핸들 {#2}

적용한 모듈의 위치를 변경하고자 할때 드래그하여 이동시킬 수 있습니다.

### 모듈 {#3}

원하는 모듈을 선택하여 드래그&드랍으로 기능을 추가합니다.
