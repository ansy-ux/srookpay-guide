## 부계정 리스트

```screen
src: images/info09_01.png
alt: 부계정 리스트
captured: 2026-10
1: 84.9 39.9
2: 21.9 62.6
3: 38.9 62.6
4: 63.1 62.6
5: 87.9 62.6
```

### 부계정 등록+ {#1}

[부계정 등록+] 버튼 클릭 시, 부계정 등록 페이지로 진입 합니다.

### 부계정 아이디 {#2}

부계정 아이디가 노출 됩니다.

### 등록일, 최근 접속일 {#3}

부계정을 등록한 날짜와 최근 접속일이 노출 됩니다. (최초로 부계정을 등록 시 등록 날짜와 최근 접속일이 동일하게 노출 됩니다.)

### 관리자 메모 {#4}

관리메뉴에서 수정 진입하면 관리자 메모를 등록할 수 있습니다.

### 관리 {#5}

[수정] 버튼 클릭시, 부계정을 수정할 수 있는 페이지로 진입하고, [삭제]를 클릭하면 부계정이 삭제 됩니다.

## 부계정 등록

```screen
src: images/info09_02_01.png
alt: 부계정 등록
1: 4.0 28.8
2: 3.9 43.4
3: 4.0 58.4
4: 4.0 81.0
```

### 아이디 {#1}

부계정 아이디를 입력합니다. 기존에 등록된 부계정 아이디와 동일한 아이디의 부계정을 등록할 수 없습니다.

### 비밀번호 {#2}

부계정 비밀번호를 입력합니다.

### 관리자 메모 {#3}

관리자 메모를 입력할 수 있습니다.

### 권한 불러오기 {#4}

권한 선택박스에서 임의의 값(그룹별 권한)을 클릭하면, 선택한 그룹별 권한에 해당하는 권한으로 자동으로 설정됩니다.

- [그룹별 권한 관리 바로가기 >] 버튼 클릭 시, 그룹별권한관리 페이지에 진입할 수 있습니다.

```screen
src: images/info09_02_02.png
alt: 권한 불러오기
```

## 권한설정

```screen
src: images/info09_03_01.png
alt: 권한설정
1: 19.5 37.2
2: 41.5 37.2
3: 50.7 37.2
4: 63.0 37.2
5: 72.3 37.2
6: 84.4 37.2
```

### 메뉴명 {#1}

상위 메뉴를 클릭하면 하위메뉴가 노출됩니다.

### 보기 {#2}

메뉴별로 노출 시킬 수 있습니다.

### 등록/수정 {#3}

메뉴별로 등록, 수정 할 수 있습니다.

### 삭제 {#4}

메뉴별로 삭제할 수 있습니다.

### 부가권한 {#5}

부가권한을 줄 수 있습니다.

```screen
src: images/info09_03_02.jpg
alt: 부가권한
```

### 전체 {#6}

전체선택을 할 수 있습니다.
