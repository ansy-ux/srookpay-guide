### 운영상태 {#1}

셀럽에게 표시되는 운영상태입니다. ON으로 설정 시 운영중으로 표시됩니다. off로 설정할 경우 셀럽에게 운영시간이 아니라고 표시됩니다.

```screen
src: images/msg_02.jpg
alt: 운영상태
```

### 운영시간 설정 {#2}

운영상태를 ON일 경우 운영시간을 설정할 수 있습니다. 설정한 요일, 시간에만 ‘운영중’으로 표시되고, 설정한 시간이 아닐 경우 운영시간이 아니라고 표시됩니다. 운영시간을 설정하지 않은 경우 항상 ‘운영중’으로 표시됩니다.

```screen
src: images/msg_03.jpg
alt: 운영상태
```

### 대화상대 {#3}

상태에 따른 대화상대를 확인할 수 있습니다. 대화 상대 클릭 시 메시지를 보낼 수 있습니다.

- 진행중 : 대화를 진행하고 있는 상태입니다. 대화를 시작하면 자동으로 진행중 상태가 됩니다.
- 완료 : 문의와 답변이 종료되고 완료 상태로 변경할 수 있습니다. 완료 상태로 변경한 이후에도 다시 대화를 시작할 수 있습니다.
- 차단 : 상대방을 차단한 상태입니다. 차단하면 상대에게 더 이상 메시지를 받지 않습니다.

```screen
src: images/msg_04.jpg
alt: 대화상대
```

### 채팅방 설정 {#4}

현재 열려 있는 대화 상대의 채팅방 상태를 변경할 수 있습니다.

- 차단하기 : 상대방을 차단합니다. 차단 시 상대방의 메시지를 받지 않습니다.
- 나가기 : 대화를 종료하고 채팅방을 목록에 표시하지 않습니다. 상대방이 메시지를 남길 경우 다시 진행중 상태로 채팅방이 열립니다.
- 완료 : 상태를 ‘완료’로 변경합니다.

### 문의한 상품 {#5}

셀럽이 문의한 상품이 표시됩니다.

### 메시지 입력 {#6}

상대방에게 메시지를 보낼 수 있습니다. 파일첨부 아이콘을 클릭하면 파일을 상대방에게 전송할 수 있습니다.
